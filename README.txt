## 📊 Expense Tracker — программа для учёта личных расходов

### 📝 Автор
**Журавлёва Елена**

### 📖 Описание программы
*Expense Tracker* — это простое и удобное приложение для учёта личных расходов, разработанное на языке Python с графическим интерфейсом на базе *Tkinter*. Программа позволяет добавлять, просматривать, фильтровать и анализировать расходы по категориям и датам. Все данные сохраняются в формате *JSON*, что обеспечивает надёжное хранение и лёгкий перенос информации между устройствами.

### ⚙️ Как использовать
1. Запустите файл *app.py* с помощью Python 3.
2. Введите сумму, категорию и дату расхода в соответствующие поля.
3. Нажмите кнопку **«Добавить расход»** — запись появится в таблице.
4. Для фильтрации расходов выберите категорию в выпадающем списке и нажмите **«Фильтровать»**.
5. Для подсчёта суммы расходов за определённый период укажите даты начала и окончания, затем нажмите **«Сумма за период»**.
6. Все данные автоматически сохраняются в файл *expenses.json*.

### 💡 Примеры использования

#### 1. Добавление нового расхода
- **Сумма:** 350.50.
- **Категория:** Еда.
- **Дата:** 2026-05-04.
- Нажмите **«Добавить расход»** — запись появится в таблице.

#### 2. Фильтрация по категории
- Выберите в списке категорию **«Транспорт»**.
- Нажмите **«Фильтровать»** — в таблице останутся только расходы на транспорт.

#### 3. Подсчёт суммы за период
- В поле «Период с» введите: 2026-04-01.
- В поле «по» введите: 2026-04-30.
- Нажмите **«Сумма за период»** — появится сообщение с итоговой суммой расходов за апрель.

#### 4. Просмотр всех расходов
- Просто откройте программу — все сохранённые расходы будут отображены в таблице.

Программа интуитивно понятна и не требует специальных знаний для работы. Все введённые данные сохраняются автоматически, что позволяет вести учёт расходов без риска потери информации.
